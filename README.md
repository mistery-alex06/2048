2048 Game

Un puzzle game minimalista e *disruptive*: fai scorrere le tessere su una griglia **4x4**, fondi i numeri uguali e scala i KPI fino a raggiungere la tessera **2048**! 

🎯 La Mission
Ottimizzare i flussi sulla griglia combinando le tessere dello stesso valore (2 + 2 = 4, 4 + 4 = 8...). 
Fai attenzione a non saturare le risorse: quando la griglia è piena e non ci sono mosse valide... *game over*.
